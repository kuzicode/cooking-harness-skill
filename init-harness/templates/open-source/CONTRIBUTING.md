# 参与 {{PROJECT_NAME}}

1. Fork 仓库，从 `main` 建分支。开发只用样例数据和本地环境。
2. 改动跨文件时，先开 Issue 说明问题和方案。
3. 提 PR，等 CI 通过和维护者批准。合并和部署都由维护者完成。

用 agent 协作没问题，它会读 [AGENTS.md](AGENTS.md)。你要对提交的内容负责，并确认测试真的跑过。

## 不接受的改动

见 [AGENTS.md](AGENTS.md) 的 RL 组。安全问题按 [SECURITY.md](SECURITY.md) 私下上报，不要提 PR 演示。

## 署名（DCO）

提交时加上 `git commit -s`，表示你有权提交这些内容，并同意按 [LICENSE](LICENSE) 发布（[Developer Certificate of Origin](https://developercertificate.org/)）。

## 维护者职责

服务器、域名、线上密钥和用户数据只由维护者管理，贡献者不需要，也不应该接触。
